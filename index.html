01.

项目背景

生产与软件变化带来的挑战，驱动了自动化开发需求

PROJECT CONTEXT
⚙

生产工艺与模具结构不断变化

模具涉及定位、冷却、分型等复杂结构，自动化模板必须随着生产工艺持续升级。

◇

NX版本升级与装配结构变更

原有自动化基于旧版本和旧装配结构开发，已无法完全满足当前设计需求。

✦

目标：更新标准并开发新工具

提升设计效率和一致性、减少人为错误、支持模板复用，并推动设计结构标准化。

香水瓶吹制模具剖切示意：用于说明模具结构、型腔及装配关系。
缩短设计时间自动处理重复工作
减少人为错误固化标准与规则
提高结构标准化保证设计一致性
支持模板复用便于维护与迭代
这项工作不是为了编程而编程，而是把机械设计标准转化为可复用的工程工具。“自动化不是替代设计师，而是让设计师更专注于创造。”
02.

参数化设计（NX PTS）

把模具结构、设计规则和标准值封装为可复用模板

PARAMETRIC DESIGN

将机械设计规则转化为参数

使用 NX Product Template Studio 建立标准化模板。
将分型结构的关键尺寸转化为可配置输入参数。
参数变化后自动驱动几何更新，避免重复寻找和修改特征。
统一标准值与建模逻辑，保证不同设计人员输出的一致性。
支持模板复用、维护和后续工艺迭代。
快速配置结构
保证设计标准
减少重复建模
便于模板复用
在做自动化之前，必须先理解分型结构的作用、设计尺寸之间的关系以及设计师的建模逻辑。Mechanical Rules → Parameters → Geometry
03.

内部开发（NXOpen / VB.NET）

解决跨组件、文件管理和装配链接修复问题

INTERNAL DEVELOPMENT

面向真实设计流程开发工具

使用 NXOpen 与 VB.NET 开发面向设计师的自动化工具。

开发 Delete Component，减少删除装配节点和关联文件时的重复操作。
工具集成到内部开发工具栏中，便于设计人员直接调用。
Restore Links 工具开发与界面设计

工具集成到内部开发工具栏
降低手动检查和修复时间
程序通过检测、分类、匹配、修复与验证，将复杂装配中的链接问题转化为可操作的流程。Detect → Match → Repair → Validate
04.

困难与收获

理解设计逻辑、覆盖多场景，并持续优化方案

CHALLENGES & LEARNING

装配结构复杂、链接依赖关系多

模具装配中存在大量 WAVE Links 和 Interpart Expressions，需要准确理解组件之间的几何与参数来源。

理解设计师的设计思路

自动化方案不能只根据程序逻辑设计，需要理解设计师如何建模、修改和处理例外情况，并据此不断优化操作流程。

反复测试多种应用场景

通过不同模具、不同断链状态和不同装配结构进行测试，持续修正边界条件，确保程序可靠性。

收获与成长

掌握 NX PTS 参数化方法和模板开发
熟悉 NXOpen 二次开发与界面设计
理解模具设计标准和复杂装配逻辑
提升问题分析、测试验证与持续优化能力
增强跨团队需求沟通与协作能力
最终形成了从标准理解、模板开发、工具实现、测试验证到落地应用的完整闭环。“自动化让设计更高效，也让工程更可靠。”
